Edit the survey as JSON. "{ } Edit JSON" on the map opens the survey in the same shape `⇩ JSON`
downloads, editable in place (or load a file): change a `distanceCm`, set or clear `verifiedAt`,
add a point or a measurement, delete a measurement's row. "Preview changes" lists exactly what
that means; "Apply" runs it as ordinary operations — each permission-checked, on the History and
re-solved — and says where it stopped if one fails.
